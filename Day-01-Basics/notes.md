## Key Concepts

### SELECT
Used to choose the columns to retrieve.

### WHERE
Used to filter rows based on a condition.

### AND
All specified conditions must be true.

### OR
At least one condition must be true.

### ORDER BY
Used to sort query results.

- ASC → ascending
- DESC → descending

### DISTINCT
Removes duplicate values from the selected result.

## Interview Takeaways

- `WHERE` filters rows.
- `ORDER BY ... DESC` is commonly used for highest-to-lowest problems.
- Multiple conditions can be combined using `AND` / `OR`.
- `DISTINCT` retrieves unique values.
- `IN` can later be used as a cleaner alternative when checking
  multiple values.
