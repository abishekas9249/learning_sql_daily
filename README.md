### Important Learning Workflow

For each new SQL day:

1. Start with a clear explanation/context of the topic.
2. Use a consistent `employees` table example.
3. Explain concepts with practical SQL examples.
4. Give me **10 practice questions**, progressively increasing in difficulty.
5. Do NOT give the solutions initially.
6. I will submit my answers.
7. Check each answer and give me the **exact corrected SQL query** with a short explanation.
8. Include an **interview challenge**.
9. After I finish the questions, prepare:

   * `queries.sql`
   * `notes.md`
   * Git commands for that day's completion.
10. My notes should include **table examples for each important concept**, because I use them later for revision.
11. Keep the learning focused on **Java Backend Developer / SQL interview preparation** and real-world backend/reporting scenarios.
